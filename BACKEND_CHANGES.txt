main.py CHANGES:
  - After app.include_router(create_api_router()):
      FastAPIAuth().protect(app, public=[...]) when middleware enabled
  - No x-service-key skip on middleware
  - Sets AI_PLATFORM_CONFIG env to path of ai-platform-config.yml when enabled

guard.py CHANGES:
  - PUBLIC: /docs, /openapi.json, /redoc, /api/v1/health/live, /api/v1/health/ready
  - PUBLIC_API_KEY_ROUTE_PATTERNS (no JWT at middleware; X-Api-Key in handlers):
      /api/v1/invoke*
      /api/v1/agents/*/execute

settings.py NEW FIELDS (.env):
  AUTH_MIDDLEWARE_ENABLED=false          # set true after wheels + config
  AI_PLATFORM_CONFIG_FILE=ai-platform-config.yml

AUTH MODEL (execution service):
  | Routes                                      | Auth at edge              |
  |---------------------------------------------|---------------------------|
  | threads, runs, deployments, audit, workflow | Bearer JWT (middleware)   |
  | /api/v1/invoke/*                            | X-Api-Key (invoke_controller)|
  | POST /api/v1/agents/{agent_id}/execute      | X-Api-Key (invoke_controller)|
  | health + OpenAPI                            | public                    |

WHAT TO DO (step by step):
  1. Copy wheels into execution-service/wheels/
  2. pip install --find-links "./wheels" ccil-webapi-middleware-fastapi==1.2.0 ...
  3. cp ai-platform-config.yml.example ai-platform-config.yml
     Edit jwt / Redis settings from platform team
  4. cd execution-service && python -m ccil_webapi_middleware   (config check)
  5. In .env: AUTH_MIDDLEWARE_ENABLED=true
  6. Start from execution-service directory: agent-execution

NOTE: Outbound calls to tool execution service still use X-Service-Key in
  local_tools_client.py (TOOL_EXECUTION_SERVICE_KEY) — not inbound API auth.
